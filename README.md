# Login System

A responsive login interface built with HTML, CSS, and JavaScript.

## Features

- Email format validation
- Password requirements validation
- Password strength meter
- Show and hide password control
- Remember email with local storage
- Accessible form messages
- Responsive mobile layout

## Run

Open `index.html` in a browser, or run a local server:

```powershell
cd "C:\Users\GuestUser\Documents\ridwan\Pynexia Tech Projects\weektwo\login-system"
python -m http.server 8000
```

Visit `http://localhost:8000`.

This is a front-end demonstration only. It does not authenticate against a server or store passwords.
